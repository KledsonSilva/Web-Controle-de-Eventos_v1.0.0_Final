# Sistema de Controle de Eventos versão: 1.0.0

## Descrição

Sistema Web desenvolvido em Java para gerenciamento de eventos e participantes.

## Tecnologias Utilizadas

- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat
- HTML5
- CSS3

## Funcionalidades

* Cadastro de Eventos

* Edição de Eventos

* Exclusão de Eventos

* Cadastro de Participantes

* Edição de Participantes

* Exclusão de Participantes

* Associação Evento x Participante

* Dashboard Estatístico

* Página Sobre

## Banco de Dados

Banco: churrasco_db

Arquivo para restauração:

churrasco_db.sql
